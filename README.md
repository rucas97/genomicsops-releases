# GenomicsOps Releases

This repository hosts **release binaries only**. Source code is not published here.

## Download

See the [Releases](../../releases) page for the latest Windows installer.

## System requirements

- Windows 10 (build 19045 or later) or Windows 11, x64
- 8 GB RAM recommended
- ~220 MB installer, ~6.5 GB for reference data

## Installation

Windows SmartScreen may warn that the app is unrecognized. This is expected for
a build that is not yet code-signed. Click **More info** → **Run anyway** to
proceed.
